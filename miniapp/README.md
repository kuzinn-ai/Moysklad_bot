# Первый экран Mini App

`index.html` — мобильный интерфейс остатков и черновика закупки. Обычное открытие в браузере показывает демонстрационные товары. Параметр `?demo=1` явно включает макет. При открытии через Telegram из inline-кнопки страница отправляет Telegram `initData` серверу и получает живые остатки через `GET /api/stock`.

## Что уже подключено

- Сервер Mini App запускается вместе с `main/bot.py` на порту `8000` (или на порту из переменной окружения `PORT`).
- Сервер отдаёт эту страницу и читает остатки через существующий `StockSalesReport`.
- Перед выдачей данных сервер проверяет подпись Telegram, срок действия `initData` и ID пользователя из `main/config.py`.
- Кнопка открытия приложения в боте использует inline-кнопку Telegram, которая передаёт данные пользователя для серверной проверки. Кнопки Web App в обычной клавиатуре Telegram для авторизованного доступа к складским данным не используются.
- API Mini App содержит только запрос чтения остатков Paradise. Изменение товаров, цен и складских остатков не выполняется.
- В список закупки можно добавить товары и поменять нужное количество. Пока это временный черновик в памяти страницы: отправка владельцу и сохранение списка не подключены.

## Для открытия внутри Telegram

Telegram требует публичный HTTPS-адрес. После размещения сервера у хостинг-провайдера добавьте в конфигурацию запуска PyCharm переменную `MINIAPP_URL` со значением этого адреса, например `https://имя-приложения.example.com`. Токены Telegram и МоегоСклада не добавляйте в URL и не отправляйте в браузер.

В `main/bot.py` кнопка открытия Mini App появляется только если `MINIAPP_URL` задан и начинается с `https://`. Без него обычные команды бота остаются доступными.
