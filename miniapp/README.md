# Mini App

`index.html` — общий шаблон Mini App. Сервер отдаёт адреса `/` (остатки), `/purchase` (закупка), `/orders` (заказы покупателей) и `/analysis` (ABC‑XYZ). Переходы по нижней навигации происходят внутри открытого документа с обновлением адреса и истории браузера; прямое открытие каждого адреса также работает. Категории и поиск обновляются без перезагрузки. Серверная часть находится в `main/miniapp_server.py` и запускается вместе с ботом.

## Авторизация

- В Telegram Mini App отправляет Telegram `initData`; сервер проверяет подпись, срок действия и Telegram ID из локального `main/config.py` или серверной переменной `TELEGRAM_USER_IDS`.
- Для локальной разработки можно временно установить `MINIAPP_LOCAL_DEV=1`: сервер будет доступен только с локального компьютера. API, включая чтение остатков и рекомендаций, по-прежнему требует действительную подпись Telegram.
- Не задавайте `MINIAPP_LOCAL_DEV` на сервере. Заказы покупателей всегда требуют действительную подпись Telegram.

## Локальная проверка

Для просмотра интерфейса без Telegram запустите локальный сервер и откройте `http://127.0.0.1:8000/?demo=1`. Демо-данные не обращаются к МоемуСкладу. Этот параметр сохраняется при переходе между страницами. Для проверки живых данных откройте Mini App из Telegram с разрешённого аккаунта. Открытие `index.html` как локального файла не поддерживает серверные адреса страниц.

## Запуск в Telegram

Telegram требует публичный HTTPS-адрес. На сервере задайте `MINIAPP_URL` этим адресом. Бот показывает inline-кнопку Mini App, если переменная указана и начинается с `https://`. Эту же ссылку можно назначить кнопкой меню бота в BotFather.

## Заказы и хранилище

Заказы покупателей и фотографии хранятся на сервере: SQLite-файл задаётся `CUSTOMER_ORDERS_DB`, каталог фотографий создаётся рядом с файлом. Каждый пользователь видит и удаляет только свои заказы; это проверяется сервером по подтверждённому Telegram ID. Укажите путь к базе на постоянный диск хостинга, иначе данные могут исчезнуть при замене контейнера. Черновик закупки хранится в браузере пользователя.

## ABC‑XYZ

Страница «ABC‑XYZ» доступна в нижней навигации по адресу `/analysis`. По умолчанию расчёт использует три последних полных календарных месяца по московскому времени. Даты «С» и «По» позволяют выбрать любой период до одного года включительно и не позднее сегодняшнего дня; обе даты входят в расчёт. Учитываются выручка по проведённым розничным продажам за вычетом возвратов и недельный спрос в штуках. ABC: первые 80% выручки — A, следующие 15% — B, остальные — C. XYZ: коэффициент вариации недельного спроса до 0,5 — X, до 1 — Y, выше — Z. Менее трёх недель с продажами и товары без продаж относятся к Z; товары без продаж и с текущим остатком — CZ. Заказы покупателей и черновик закупки в расчёт не входят.

Последний результат сохраняется в `abc_xyz_snapshot.json` рядом с базой заказов на постоянном диске. При выборе другого периода снимок заменяется, а «Обновить расчёт» повторно запрашивает данные МоегоСклада. Кнопка «Скачать Excel» формирует файл из полного сохранённого снимка выбранного периода: листы «Итоги» и «Товары», без формул и без постоянного хранения файла на сервере. Остаток в отчёте — текущий на момент расчёта, не исторический. Анализ не меняет черновик закупки.
